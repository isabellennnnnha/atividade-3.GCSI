# atividade-3.GCSI

Este repositório contém uma atividade desenvolvida durante o semestre atual do curso de Informática.

## Descrição

O projeto apresenta uma lista de produtos utilizando JavaScript.

Os produtos são armazenados em um array de objetos e são exibidos dinamicamente na página HTML.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Armazenamento de produtos em um array
- Utilização de objetos
- Exibição dinâmica dos produtos
- Interação através de botão
